# 🌐 Интерактивная система обучения правилам поведения в сети

Десктопное приложение для обучения и тестирования учащихся в сфере кибербезопасности. 

## 🛠 Технологический стек
* **Язык программирования:** C#
* **Технология интерфейса:** WPF (Windows Presentation Foundation)
* **База данных:** SQLite (хранение прогресса и истории ответов)
* **Архитектура и данные:** JSON (динамический контент)
* **Графика и диаграммы:** LiveCharts

## 🚀 Основные возможности
* **Удобное обучение:** Теория подгружается из расширяемых JSON-конфигов без необходимости пересборки проекта.
* **Интерактив:** Реализована механика Drag-and-Drop с плавными анимациями для закрепления материала.
* **Контроль знаний:** Система тестирования с фиксацией результатов в локальной БД.
* **Аналитика:** Наглядные диаграммы прогресса и статистики ответов для пользователя.
